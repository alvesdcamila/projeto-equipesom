# Pacote de continuidade — Projeto EQUIPESOM

Versão do pacote: 0.1  
Data de consolidação: 03/08/2026

Este pacote transfere o contexto útil da conversa original para o Projeto EQUIPESOM. Ele não é uma transcrição literal: decisões, evidências, divergências e pendências foram reorganizadas para que uma nova conversa consiga continuar sem reconstruir todo o raciocínio.

## Ordem recomendada para anexar e usar

1. `01_CONTEXTO_MESTRE_EQUIPESOM.md`
2. `02_REGISTRO_DE_DECISOES.md`
3. `03_ROADMAP_E_STATUS.md`
4. `04_PROMPT_DE_CONTINUIDADE.txt`
5. `05_MODELOS_RECOMENDADOS_CODEX.md`
6. `06_INVENTARIO_INICIAL_EQUIPESOM.csv`
7. `Inventario_Produto_Equipesom_v0.2.0.xlsx`
8. `Blueprint_Produto_Orcamentos_v0.1.pdf` ou a versão `.docx`
9. Os cinco PDFs históricos de propostas e o cartão CNPJ, caso ainda não estejam anexados no Projeto EQUIPESOM.

Se houver limite de anexos, priorize o contexto mestre, a planilha v0.2.0, o Blueprint em PDF, o prompt de continuidade e os documentos reais.

## Como iniciar a conversa no projeto

Depois de anexar os arquivos, abra uma nova conversa e cole o conteúdo de `04_PROMPT_DE_CONTINUIDADE.txt`. O Codex deverá ler os arquivos antes de propor mudanças.

## Regra de atualização

- Não sobrescrever uma versão emitida ou aprovada.
- Criar nova versão quando uma decisão mudar.
- Registrar origem, data e responsável por novos dados.
- Não transformar hipóteses, grafias incertas ou textos jurídicos preliminares em fatos.

## Estado atual

O projeto está na fase de descoberta e desenho do esqueleto. Ainda não é o momento de iniciar a programação completa. O próximo marco é fechar o inventário operacional e aprovar o modelo de dados e os fluxos do MVP.
